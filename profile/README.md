# Welcome to Statistics Norway 👋

Statistics Norway is committed to open source and we aspire to share as much of our work as possible. We are primarily funded by Norwegian taxpayers and wish to be transparent and contribute to innovation.

On our Github organization you will find everything from platform code to frontend. We share the tooling and workspaces we use in the collection, development, processing and dissemination of statistical data, in the name of transparency. The source code for our website is also here, and you can visit it at [https://www.ssb.no](https://www.ssb.no)
